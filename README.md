# Barge — Release Artifacts

This repository hosts signed + notarized macOS builds of [Barge](https://github.com/a18n/barge), an ambient video presence app for friends.

The source code lives in a private repository. This repo contains release binaries and the `latest-mac.yml` manifest used by the in-app auto-updater.

## Installing

Grab the latest `.dmg` from the [Releases page](https://github.com/a18n/barge-releases/releases/latest):

- **Apple Silicon (M1/M2/M3/M4):** `Barge-<version>-arm64.dmg`
- **Intel:** `Barge-<version>.dmg`

Open the .dmg and drag Barge to Applications.

## Updates

Once Barge is installed and running, future versions arrive automatically via the in-app auto-updater. No manual reinstalls needed.
